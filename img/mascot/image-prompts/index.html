    Mascot Image Prompts: Kit the Otter

    I am about to ask you to generate seven different poses for a book mascot. Please use a consistent drawing style for all seven images.

    Each prompt below is fully self-contained — the complete character description is repeated in every one, so you can paste any single prompt into an image generator without carrying context from the others. Do not shorten them. The description must stay identical across all seven or the poses will drift.

    Generate at 1024x1024, save as RGBA PNG into docs/img/mascot/, then run the padding trimmer (see the bottom of this page).

    The canonical description lives in character-sheet.md. If you change anything here, change it there too.

mascot for a textbook about portable AI agent skills for building intelligent
textbooks. Kit is a small, round sea otter kit with warm brown fur (#8d6e63)

slung bandolier-style across the chest, with three small tool loops on the

warm closed-mouth smile. The character is small and compact with a large head

flat vector, solid color fills, no gradients, bold clean outlines, transparent
background with alpha channel, suitable for embedding in educational content.

Kit stands upright in a relaxed, neutral pose facing the viewer directly, with
a calm and friendly closed-mouth smile. Both paws rest naturally at their
sides with no specific gesture. The pose is balanced and unassuming —
suitable as a general-purpose or default illustration.

    After Generating: Trim the Padding

    AI image generators add excessive transparent padding, which makes Kit appear far too small inside a 90px admonition. Save all seven PNGs to docs/img/mascot/, then run the trimmer from the project root. (This repo ships the trimmer itself, so the path is local; in a book repo elsewhere the path is $BK_HOME/src/image-utils/trim-padding-from-image.py.)

    1
2

    python src/image-utils/trim-padding-from-image.py docs/img/mascot/neutral.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/welcome.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/thinking.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/tip.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/warning.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/encouraging.png
python src/image-utils/trim-padding-from-image.py docs/img/mascot/celebration.png

    Then open learning-graph/mascot-test/ in the running site and confirm every pose reports a 4/4/4/4 margin. Fix any failing image by rerunning the trimmer — never weaken the check to make the page pass.

    Required specifications

    • Format: RGBA PNG with a fully transparent alpha-channel background
    • Display dimensions: 200x200 to 400x400 pixels after trimming
    • File size: under 100KB per image
