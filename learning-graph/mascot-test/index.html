    Kit Mascot Image Test

    This page tests every production mascot PNG in two ways:

    1. Each image is drawn over checkerboard and dark backgrounds so opaque boxes, halos, and edge contamination are easy to spot.
    2. A browser-side pixel test checks for an RGBA transparency region, transparent corners, and the 4 px content border produced by trim-padding-from-image.py (using the script's alpha threshold of 10).
